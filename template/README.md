# 微信

在本机只读查看自行选择的个人微信私聊和群聊。需要 macOS arm64、Node 24、Worka 0.3，以及已单独初始化的微信读取组件。第三方读取方案，非腾讯官方接口。

市场只安装便笺界面，不会安装后台或初始化微信。先按[项目安装说明](https://github.com/kllilizxc/dsh-worka-wechat#安装)安装 `dsh-worka-wechat` DSH 插件并准备本机配置，再恢复市场添加的便笺。缺少 `wechat` 能力时，按 Worka 的依赖提示完成配置。

每个 Worka 宿主当前仅支持一个微信便笺；已有便笺时继续使用原便笺。新安装没有预选会话，也不会自动开始读取。

安装后先通过 Worka 的恢复入口启用便笺，再展开点“选择会话”，勾选私聊或群聊，点“保存并读取”。自动读取默认每 5 秒检查一次，错误时由 Worka 退避重试。
每个会话先读取最近 50 条，再沿持久游标获取新消息，保留最近 200 条。只显示文字，媒体消息显示类型提示。
Mac 微信需保持登录；休眠期间不能读取，醒来后续读。暂停便笺或桌面会停止后续读取，恢复后续读。
消息只保存在本机插件私有目录，不进入便笺状态、模型上下文或自动 AI 连线。界面无回复入口。

保持 SIP 开启，不保存管理员密码，不执行上游自动初始化或升级。微信升级后需重新验证兼容性。群聊入站、私聊历史及出站增量已验证；私聊新入站和长期运行稳定性尚未完成验证。
