# 微信

在本机只读查看此便笺选择的微信私聊和群聊，使用 manifest 声明的 `@realiz3r/worka-provider-wechat`（`worka-wechat`）。不会发送微信消息。

首次打开使用 Worka 的统一“一键初始化”，自动准备已校验的读取组件，处理必要的本机授权，并对文件传输助手完成最多一条真实读取。需要密码或扫码时按系统提示完成；无需手动安装后台、填写密钥路径或复制配置。真实读取通过后，便笺显示会话和消息。失败会保留实际原因，可重试或交给 Agent 修复。

连接后可选择最多 20 个会话、暂停或恢复此便笺的读取。消息、游标和处理反馈保存在本机；已选会话的新消息会发布变化事件；连线自行决定如何处理。跟进或略过由便笺本地回执保存，连线负责业务协调。

宿主按便笺声明安装并核验 provider。消息、配置和登录状态不随便笺发布。微信升级后应重新核验真实读取；组件就位或对话完成均不代表连接成功。

会话按最新消息排序；未读红点只记录此便笺的查看位置，打开会话后单调推进，不影响微信客户端。`item/context` 提供已选会话缓存供理解上下文。事件中的 `fromMessageId` 和 `messageId` 分别是本批之前的最后一条消息（无先前消息时为 null）和本批最后一条消息，连线通过 `batch` 只处理该范围，并维护自己的消费位置。
